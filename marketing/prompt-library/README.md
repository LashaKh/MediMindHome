## How decisions carry forward

- Strategy recommendation is not customer validation.
- A public product description is not proof of clinical or financial results.
- A real hospital is not automatically a qualified sales opportunity.
- A forecast remains a scenario until inputs are known.
- Source material does not authorize contacting prospects, publishing campaigns, buying tools, changing tracking, or deploying new page copy.
- Each completed section should be reviewed for meaning and factual corrections before treating it as fixed input to later creative work.
